# HER SUPPORT — Assignment 2 Website

HER SUPPORT is a responsive website designed to provide girls and young women with information about mentorship, guidance, legal support and useful resources.

## Website Pages

- `index.html` — Home
- `about.html` — About HER SUPPORT
- `services.html` — Support services
- `mentor-booking.html` — Mentor booking
- `file-complaint.html` — File a complaint
- `contact.html` — Contact information

## Technologies Used

- HTML5 for website structure
- CSS3 for styling and responsive layouts
- SVG and PNG images for visual elements

## How to Run the Website

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using the Live Server extension, or open the file in a browser.
4. Use the navigation menu to visit the other pages.

## Project Assets

The `assets` folder contains the images, logo and icons used throughout the website. The `her.png` image is stored in the project root folder.

## Notes

This project was developed for Web Design Assignment 2. The website is a front-end demonstration. Forms do not transmit or store submitted information unless a backend service is added.
